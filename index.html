Audit your Python repository before it ships.

QuantumAI reads your code with Python's own AST, flags risky patterns on your machine, then asks OpenAI to review what it found and write your README.

Install QuantumAI View source on GitHub

What it does

Local AST scan
Parses every file and records classes, functions, imports and complexity. Built-in rules catch eval, unsafe pickle and YAML loading, SQL built from strings, shell=True, disabled TLS checks, weak hashes and hardcoded secrets.
AI review
Sends the structured findings to gpt-4o-mini (or the model you choose) to confirm real issues, explain the impact, and suggest a fix. It also looks for security and performance risks the local rules cannot see.
README writing
Turns the same project summary into a complete English README with overview, install steps, usage and project structure. It will not overwrite an existing README unless you pass --force.
Built for CI
Export a JSON report with --output and fail the build at a severity you choose with --fail-on high. Use --no-ai to run fully offline.

Your source files stay on your machine

QuantumAI never uploads whole files. The model only sees the metadata below, and you can skip the upload entirely with --no-ai.

Sent to OpenAI

  • File paths and import names
  • Class and function names, argument names, complexity
  • Findings, each with the one flagged line (trimmed)

Never sent

  • Full source files or function bodies
  • The line holding a hardcoded secret
  • Your API key, which stays in OPENAI_API_KEY

Install and run

Requires Python 3.9 or newer and an OpenAI API key.

1. Install from PyPI

pip install quantumai

2. Set your API key

export OPENAI_API_KEY="sk-..."

3. Audit a project and write its README

quantumai audit ./my-project
quantumai readme ./my-project

Prefer the source? git clone https://github.com/your-username/quantumai && pip install -e .
